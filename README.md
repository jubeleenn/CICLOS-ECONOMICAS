Manual de usuario:

Instalar el git si no lo tienen instalado

Windows
Descargar Git desde:
https://git-scm.com/download/win
Ejecutar el instalador.
Dejar todas las opciones por defecto (Next, Next, Next).
Finalizar instalación.
Abrir “Git Bash” o “Terminal”.
Verificar instalación:

Antes de comenzar, verificar que Git esté instalado.

Comprobar instalación:

git --version

Clonar el repositorio

Abrir una terminal y poner

cd Documentos o Documents 

y despues clonar el repo
git clone https://github.com/jubeleenn/CICLOS-ECONOMICAS.git 

Ingresar al proyecto con 

cd CICLOS-ECONOMICAS.git 

Y AHORA PARA VER LAS PAGINAS ABAJO HAY UN BOTON QUE DICE GO LIVE DAS CLIC AHI Y YA ESTA
